- `shield_arc_max` / local shield-hit type is widened incorrectly to `uint16_t`; the binary uses an 8-bit signed source (`BL` from `_planetary_shields[*].absorption`) and stores it to a 16-bit field via sign/zero-preserved `BX`. - The beam / PD / missile slot counts are written through `(uint8_t)` casts, but the target fields are signed 8-bit (`int8_t count`, `int8_t shots_left`, `int8_t ammo`). The binary writes raw 8-bit register values; explicit unsigned casts are a type smell and can hide signedness mistakes.
  ```diff

+ MOX::_combat_data->weapons[0].count = (int8_t)count_1;
  ```
